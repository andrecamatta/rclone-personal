Privacy policy

Last updated: November 12, 2026.

This OAuth client is used by a single person, its owner, to access the owner's own Google Drive files with rclone running on the owner's own computers.

Data accessed

With the owner's authorization, rclone reads and writes files and file metadata in the owner's Google Drive.

Data storage and sharing

Files and access tokens stay on the owner's own machines. No data is collected by this site, sent to any third party, sold, or used for advertising. There are no other users.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
